# Основы систем мобильной связи

Автор: Павлова Виктория Андреевна
Курс: Основы сотовых и мобильных систем связи (СибГУТИ)
Стек: MATLAB, Python, Signal Processing Toolbox

## Реализованные задачи
### Лабораторные работы: Спектральный анализ
- БПФ (FFT): Реализация алгоритмов быстрого преобразования Фурье для анализа частотных характеристик.
- Оконные функции: Сравнение эффективности окон Хэмминга и Хэннинга для минимизации утечки спектра.
- Обработка аудио: Фильтрация и визуализация речевого сигнала (voice.wav). Построение АЧХ и ФЧХ.

### Расчетно-графическая работа (РГР): Моделирование канала
- Модуляция: Реализация схем BPSK и QPSK для передачи данных в зашумленном канале.
- Анализ помехоустойчивости: Расчет вероятности битовой ошибки (BER) в зависимости от отношения сигнал/шум 
- Моделирование шума: Генерация аддитивного белого гауссовского шума (АБГШ / AWGN) для имитации реальных условий радиоканала.
- Визуализация: Построение диаграмм созвездий (Constellation Diagrams) для оценки искажений сигнала.

### Технологии
- MATLAB: Основное средство для математического моделирования и ЦОС.
- Signal Processing Toolbox: Использование встроенных функций для БПФ, фильтрации и генерации шумов.
- Python: Вспомогательные скрипты для обработки данных.
- LaTeX/Word: Оформление технической документации.
