## Реализованные задачи
### Лабораторные работы: Спектральный анализ
- БПФ (FFT): Реализация алгоритмов быстрого преобразования Фурье для анализа частотных характеристик.
- Обработка аудио: Фильтрация и визуализация речевого сигнала (voice.wav). Построение АЧХ и ФЧХ.

### Расчетно-графическая работа (РГР): Моделирование канала
- Модуляция: Реализация схем BPSK и QPSK для передачи данных в зашумленном канале.
- Анализ помехоустойчивости: Расчет вероятности битовой ошибки (BER) в зависимости от отношения сигнал/шум 
- Визуализация: Построение диаграмм созвездий (Constellation Diagrams) для оценки искажений сигнала.
**Расчет CRC (Cyclic Redundancy Check):** 
    *   Реализация алгоритма вычисления контрольной суммы для пакетов данных различной длины.
    *   Исследование влияния выбора **порождающих полиномов** на вероятность обнаружения ошибок.
    *   Сравнительный анализ "хороших" и "плохих" полиномов (с отсутствием младшего члена $x^0$) и их устойчивости к пакетным ошибкам.
*   **Корреляционный анализ:**
    *   Расчет **автокорреляционной функции (ACF)** для синхропоследовательностей.
    *   Расчет **взаимной корреляции** между переданным и принятым сигналом для оценки качества синхронизации.
    *   Нормировка корреляционных функций для корректного сравнения сигналов с разной энергией.
*   **Моделирование канала:** 
    *   Генерация аддитивного белого гауссовского шума (AWGN).
    *   Оценка вероятности необнаруженной ошибки в зависимости от длины пакета и степени полинома.
